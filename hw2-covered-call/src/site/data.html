Data connection required

Pulling prices needs LSEG Workspace running and signed in on the same machine. GitHub Pages serves static files only, so there is nothing here to connect to.

Rebuilding the book

With Workspace open:

python3 fetch.py AAPL.O --weeks 10 --strike-step 5
python3 run_backtest.py AAPL --rule nearest_otm
python3 build_site.py AAPL MPWR

The fetch step is the only one that touches the API. It caches to data/raw_AAPL.json, so the backtest and the site can be rebuilt as many times as needed without spending more of the daily request budget.
